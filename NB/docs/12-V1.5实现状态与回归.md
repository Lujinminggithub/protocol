# NB V1.5 实现状态与回归

## 1. 已完成

- 自动 FEC 默认观察模式，普通 QUIC 为稳定基线；
- 独立 RS(k,r) FEC 模块；
- 多 block 乱序窗口、BDP TX history、NACK 重试、RETX ACK、FIN/RST；
- FEC payload 完整性、乱序、恢复和 netem 矩阵工具；
- 环形发送队列、TCP 高低水位背压、epoll、O(1) session 索引；
- legacy 双发、flowid 配对和 `picoquic_add_to_stream` 全部移除；
- 节点 mTLS、服务端证书校验、SOCKS RFC 1929、PBKDF2 凭据；
- entry/exit fail-closed 白名单和部署密钥管理；
- `SO_REUSEPORT` 多 worker、加权多出口和按地址独立连接池；
- 本机只读 Unix socket 控制面。

## 2. 代码级回归结果

- FEC 多 block 逆序交付：通过；
- RS 恢复与精确 payload 字节数：通过；
- NACK 丢失后的重试、RETX、RACK、BACK：通过；
- 精确 block 边界 FIN 与非法报文边界：通过；
- RS 组合测试：144/144 通过；
- 环形队列 wrap/grow/limit：通过；
- SOCKS PBKDF2 正确、错误和未知用户：通过；
- 控制 socket 权限、命令和 JSON：通过；
- 加权出口路由：通过；
- 双 worker 监督器：通过；
- 完整 Linux `nb_node` 链接与动态依赖检查：通过，零告警；
- 安全 SOCKS 三跳 loopback：错误密码拒绝、三端控制面健康、10/10 HTTP 200、300KB SHA-256 一致。

## 3. 尚未完成的阶段验收

- 尚未在重装后的三台真实服务器执行本轮安全部署；
- 自动 netem 矩阵尚未针对真实三跳运行；
- 无 FEC 普通 QUIC 手机直播基线尚未重新验收；
- FEC active 对照直播尚未进行。

这些项目属于部署与线路阶段验收，不能由代码级单元测试替代。
