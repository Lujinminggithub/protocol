# 线路自包含上下行能力设计

## 目标

将上下行能力完全收归线路业务域。三节点和香港单节点开线都只填写一组端到端上行与下行，不再要求、推导、汇总或校验物理链路容量。

## 业务口径

- 每条线路独立维护 `upstream_mbps` 和 `downstream_mbps`。
- 上行表示当前线路从客户端经 Entry 到 Exit 的业务方向。
- 下行表示当前线路从 Exit 经 Entry 返回客户端的业务方向。
- 三节点线路只填写一组上下行，不填写 Entry 到 Relay、Relay 到 Exit 的分段能力。
- 共享 Entry、Relay 或 Exit 不引入线路间容量汇总，也不形成隐藏门禁。
- 香港单节点线路使用同一组上下行字段，语义不变。
- 线路开通、修改、验证、调优、删除只处理当前线路。

## 产品界面

### 线路

线路创建表单保留并强化上行、下行输入。这两个字段是开线能力的唯一来源。生产和测试线路均要求两个方向分别大于零；`bandwidth_mbps` 只作为兼容派生字段，取上下行较大值，不作为独立输入。

线路列表展示“上行 / 下行”而不是单一带宽。线路详情展示配置目标、最近实测速率和两个方向的验收状态。

### 物理链路

删除一级导航“物理链路”及新增、编辑、筛选物理链路的界面。任务与线路详情不再链接到物理链路管理。

历史 `network_links` 数据暂时保留在数据库中用于审计和兼容读取，但不再参与新业务流程。已有读取 API在过渡期保留，写 API标记为退役并拒绝新写入。

### 流量分析

流量分析详情保持当前状态，明确不在本次改动范围内：

- 保留线路总览以及 Entry、Middle、Exit 分段曲线；
- 保留每个角色的上行、下行序列；
- 保留实时模式、历史时间区间、快捷时间范围和证据时间轴；
- 保留流量历史、流式快照和事件定位 API；
- 不改变采集口径、图表配色、角色名称或现有历史数据。

分段流量图是观测视图，不代表分段物理链路容量配置。

## 控制面数据流

线路保存时，服务端校验两个方向均大于零，并将 `bandwidth_mbps=max(upstream_mbps,downstream_mbps)` 写入兼容字段。开线任务计划直接携带当前线路的两个方向，Worker 和 `line_open.py` 原样传递到 Node 实例策略。

不再调用以下业务流程：

- `ReserveLineCapacity`；
- `ActivateLineCapacity`；
- 按拓扑匹配 `network_links`；
- 计算 forward/reverse 可用容量；
- 物理链路 `capacity_unknown`、`capacity_insufficient` 或计费模式治理；
- 删除线路时释放物理链路容量预留。

保留数据库表和历史清理代码必须是幂等的，但没有新记录写入。

## 开线与验收

开线门禁只检查：

- 线路拓扑和设备可用性；
- 端口与实例资源冲突；
- 上行和下行配置有效；
- Node 候选和运行时版本要求；
- 安全材料、白名单、DNS 和出口配置。

验证与协议调优分别使用 `upstream_mbps` 和 `downstream_mbps` 作为目标。两个方向仍独立验收，任何一个方向不足都只导致当前线路拒绝，不影响其他线路。

现有“10 Mbps 全双工”线路继续表示上行 10 Mbps、下行 10 Mbps，不解释为双向合计 10 Mbps。

## 治理与兼容

- 删除物理链路容量相关治理项，不再阻止生产开线、升级或调优。
- 保留全双工资格、设备状态、Node 版本和端口冲突治理。
- 历史线路若只有 `bandwidth_mbps`，迁移时继续回填为同值上下行。
- 历史物理链路和容量预留数据不得影响任何新任务。
- API返回的旧字段在兼容期保留，前端不再展示或写入。

## 删除与清理

线路删除仍必须精确清理三端实例、端口、客户端配置和线路记录。物理链路不可用或历史预留异常不能阻止删除。历史容量预留的清理为尽力而为，不参与删除成功判定。

## 测试

- Store 测试证明开线不创建 `line_capacity_reservations`。
- Web 测试证明物理链路导航和编辑入口不存在，线路表单只提交一组上下行。
- API 测试证明物理链路写接口拒绝写入，兼容读取仍可用。
- 开线测试证明共享设备上的多条线路互不进行容量汇总或拒绝。
- 治理测试证明物理链路缺失、容量不足和计费模式不再产生发现项。
- 线路删除测试证明历史预留异常不影响删除。
- 流量分析资产和 API 回归测试保持不变，并明确验证 Entry、Middle、Exit 上下行图表仍存在。
- 三节点、香港单节点、生产和测试线路均覆盖上下行字段传递。

## 不在本次范围

- 修改 Node wire format；
- 修改流量采集或流量图表；
- 对共享节点做带宽整形聚合；
- 自动推测运营商物理链路容量；
- 立即删除历史数据库表或审计数据。
